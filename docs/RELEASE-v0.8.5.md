# XGuard v0.8.5 更新日志

发布日期：2026-11-16。同步提供 Root 模块版与免 Root 本地 VPN 版，延续原有玻璃风格界面。

## 更新内容

- **完善迅雷开屏防护**：合并原有 9 条迅雷缓存规则，加入实机发现的 `cache/roip_ad_cache`，共 10 条；补充 6 个广告 SDK 精确域名，同步到免 Root 版的域名规则。
- **修复开屏防护数量一直为 0**：概览与开屏页按实际锁定的应用数量统计；弱占位单独标注，避免把未生效路径算作有效防护。
- **规则按应用分组**：开屏防护、自定义开屏规则、发现缓存均显示应用图标、名称和包名；支持展开查看路径，并从应用分组快速添加规则。
- **提高规则添加流畅度**：保存时只处理新增路径，局部刷新当前应用，减少重复加载和卡顿。
- **加深缓存扫描**：由原先 4 层提高到默认 8 层，可选 6 / 8 / 12 层；候选按应用分组，支持应用名称、包名和路径筛选。每个应用的每个存储区域最多列出 60 项，展开后加载路径。
- **首页增加统计卡片**：模块版显示本次采集的观察记录、规则命中和命中比例；免 Root 版显示真实 DNS 请求、拦截和拦截比例，累计计数持久保存，清空日志不重置计数。
- **新增显示方式**：支持浅色、深色、随系统，保存选择并同步系统栏颜色。
- **关于页面新增 GitHub 项目链接**，方便查看源码、下载更新和反馈问题。
- **修复 SukiSU / KernelSU 挂载隔离兼容问题**：Root 命令在系统挂载空间检查与锁定缓存；补齐必要的父目录，并每 30 秒检查补锁。

## 下载与升级

| 文件 | 用途 |
| --- | --- |
| `XGuard-v0.8.5-module.zip` | Root 模块，Android 11 及以上；用 Magisk / KernelSU / SukiSU / APatch 管理器安装并重启 |
| `XGuard-v0.8.5-root.apk` | 模块版配套管理应用，需要先安装模块 |
| `XGuard-v0.8.5-no-root.apk` | 免 Root 版，Android 6.0 及以上；直接安装并授予系统 VPN 权限 |
| `XGuard-v0.8.5-source.zip` | 模块与免 Root 版源码快照，不能作为模块刷入 |
| `SHA256SUMS.txt` | 以上附件的 SHA-256 校验值 |

模块版为 `0.8.5 / 8005`，免 Root 版为 `0.8.5-noroot / 80051`。两版保留各自旧签名，可在对应版本上升级。两个 APK 同为 `com.xuan.xguard`，不能共存；切换版本类型前先备份所需设置。

## 验证与使用说明

- 已完成 Go 测试与 vet、四种 ABI 构建、两版 Java / DEX 编译、APK 签名验证，以及模块 WebUI 与内置 APK 资源一致性检查。
- 界面测试覆盖应用分组、增量保存、候选筛选、扫描深度、三种主题及刷新保持、小屏布局和 CSP。
- Root 实机验证覆盖规则增删、实际锁定计数、并发保存、解锁恢复、符号链接边界，以及 12 层与 6 层的扫描差异。
- 迅雷 `25.3.10.294` 实机确认 10 条缓存规则均可锁定；补充广告域名后的最后一轮 5 次成功冷启动截图未见广告。有限次数测试不能保证所有版本或所有启动场景均无广告。
- 免 Root 版使用独立验证包名进行实机 DNS 探针检查：广告域名返回 NXDOMAIN，普通域名正常解析，计数写入持久化存储。设备截图与私有缓存数据不随源码发布。

“开屏防护”数字表示实际锁定的应用数量。模块版“规则命中”表示观察到的域名命中规则，不能视为广告拦截次数。扫描只列候选，手动加入后才锁定；广告 SDK 缓存规则也可能影响同一 SDK 的其他广告位，可按应用解锁。

免 Root 版不能扫描或锁定其他应用的私有缓存；当前仅处理本地 IPv4 UDP DNS，占用系统 VPN 槽位。加密 DNS、QUIC、已有广告素材和应用自带解析器等仍可能影响拦截效果。模块的迅雷网络补防也不能保证覆盖加密 SNI、QUIC、分段或代理转发。
