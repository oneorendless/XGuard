# XGuard v0.8.6

## 统计与连接

- 首页增加比例环图、近 12 分钟记录分布和近期命中域名排行，模块版与免 Root 版分别使用网络观察数据与实际 DNS 累计计数。
- 模块版增加 HOSTS 防护状态、规则域名数与近期命中域名数。hosts 在本地完成解析时没有网络包，真实拦截次数无法直接计数；可见域名匹配规则也不能证明连接已经阻断。
- 最近记录图表只使用当前保留的记录，不代表完整历史或全量请求。清空域名记录会清空图表与排行，累计计数保持不变。
- 连接状态独立显示，首页改用轻量统计，避免等待全部来源详情与缓存路径检查。首页开屏数量使用后台最近核验结果，开屏页面继续读取实际锁定状态。

## 弹窗与选择

- “诊断与恢复”的日志采用与防护检查一致的可关闭弹窗，支持关闭按钮、完成、返回与点击窗口外部；部分日志读取失败时仍展示其他结果。
- 扫描深度采用玻璃风格选项卡，保留 6 / 8 / 12 层，提供用途说明与选中状态。
- 自动更新间隔采用同风格弹窗，支持选择、取消和保存，保留已有的自定义间隔；保存失败时显示原因并保留原值。
- 免 Root 版明确说明更新间隔目前仅保存偏好，规则仍需手动更新。

Root 模块及配套应用版本为 `0.8.6 / 8006`；免 Root 应用为 `0.8.6-noroot / 80061`。二次创作与维护：**Xuan**；感谢原作者 **惜故里丶**，保留原作者及第三方项目署名与许可。

## 下载与验证

- `XGuard-v0.8.6-module.zip`：Root 模块刷入包，需要 Android 11 及以上与兼容的 Root 管理器。
- `XGuard-v0.8.6-root.apk`：模块配套管理应用，单独安装不能替代模块。
- `XGuard-v0.8.6-no-root.apk`：免 Root 本地 VPN 应用，需要 Android 6 及以上。
- `XGuard-v0.8.6-source.zip`：对应版本源码，不能作为模块刷入。
- `SHA256SUMS.txt`：上述文件的 SHA-256 校验值。

两种 APK 使用同一包名、不同签名，不能共存或直接跨类型覆盖安装。免 Root 版仅处理 IPv4 UDP DNS，不覆盖所有加密 DNS 或广告内容。

两版界面回归、APK 编译、原签名和资源一致性检查通过；Root 版已在 SukiSU 设备覆盖安装，模块、防护与实际缓存锁定状态正常。本轮未重复免 Root 真机 VPN 转发测试或迅雷冷启动广告检查。完整范围见 [验证记录](https://github.com/oneorendless/XGuard/blob/main/docs/VALIDATION-v0.8.6.md)。
