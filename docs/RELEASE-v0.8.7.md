# XGuard v0.8.7

本版增加误拦截恢复能力，让规则调整和异常恢复更容易操作。

- **暂停 5 分钟**：Root 版撤下 HOSTS、网络补防和开屏缓存锁定，后台到期恢复；免 Root 版保留 VPN 转发，仅暂停 DNS 拦截。支持立即恢复，手动关闭优先于自动恢复。
- **撤销域名操作**：恢复最近一次放行、封禁或移除前的名单。名单被其他操作修改时会提示，避免覆盖后续修改。
- **更新差异与规则回滚**：显示新增、移除的规则域名数；成功更新发生变化时保存一份更新前源缓存。回滚保留当前放行、封禁名单；来源选择变更时拒绝恢复不匹配的快照。
- **Root 更新恢复保护**：回滚后自动更新暂停 24 小时，手动更新可提前结束；下载失败保留旧缓存，HOSTS 原地写入保留挂载 inode。
- **健康检查与修复**：使用可关闭的玻璃弹窗显示实际运行状态。Root 检查 HOSTS、守护与采集进程，并定期尝试恢复异常组件；免 Root 检查 VPN 权限、服务和规则加载状态，支持手动修复及服务内的工作线程重试。
- **免 Root 关闭修复**：主动关闭 VPN 通道，避免系统绑定服务导致手动关闭延迟；手动关闭或权限撤销后不会被保活逻辑重新开启。

Root 配套版本为 `0.8.7 / 8007`，免 Root 为 `0.8.7-noroot / 80071`。保留 Xuan、原作者惜故里丶及第三方署名与许可。

免 Root 的自定义订阅下载和后台定时订阅仍未完成，规则需要手动更新。Root 的网络观察与 HOSTS 真实拦截次数仍有区别；本版没有将观察记录当作实际拦截次数。

安装包包括 `XGuard-v0.8.7-module.zip`、`XGuard-v0.8.7-root.apk`、`XGuard-v0.8.7-no-root.apk`、`XGuard-v0.8.7-source.zip` 和 `SHA256SUMS.txt`。模块包需要 Android 11+ 与兼容 Root 管理器，免 Root APK 需要 Android 6+；两个正式 APK 使用相同包名和不同签名，不能共存。

验证细节及边界见 [v0.8.7 验证记录](VALIDATION-v0.8.7.md)。
