# XGuard 0.9.2

GKD 页面标题下新增蓝色重点卡片“隐藏最近任务”。默认关闭，开启后从系统最近任务列表隐藏 XGuard，关闭后恢复显示；可随时通过桌面图标重新打开应用。Root 与免 Root 版均支持，设置自动保存，重新启动应用时恢复。

模块及 Root APK 版本为 `0.9.2 / 9002`，免 Root APK 为 `0.9.2-noroot / 90021`。沿用原有应用签名、订阅开关与授权设置。

此版本为本地构建，尚未发布 GitHub Release。验证范围见 [VALIDATION-v0.9.2.md](VALIDATION-v0.9.2.md)。
