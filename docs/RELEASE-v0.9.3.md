# XGuard v0.9.3 · 日志与导航改版

## 更新内容

- **日志更易读。** 在「设置 → 查看日志」里可以先看防护状态，再按时间查看最近事件。选择「需要留意」可以集中查看失败或异常记录，展开「查看原始记录」可以看技术细节。免 Root 版会区分 DNS 请求已拦截、未拦截和查询失败。
- **底栏精简为四项。** 底栏保留「概览、域名、开屏、设置」。「域名」下可切换域名记录和规则订阅。「开屏」下可切换缓存锁定和 GKD，Root 版默认进入缓存锁定，免 Root 版默认进入 GKD。
- **减少后台刷新和写入。** 控制面板只在相关页面可见时自动刷新统计，防护暂停倒计时只在概览可见时更新。免 Root 版只在暂停状态变化时刷新 VPN 通知，运行时的统计写入间隔从 5 秒延长至 30 秒。

## 下载与升级

| 文件 | 用途 |
| --- | --- |
| `XGuard-v0.9.3-module.zip` | 用 Root 管理器安装或更新模块 |
| `XGuard-v0.9.3-root.apk` | 手动补装 Root 模块的管理界面 |
| `XGuard-v0.9.3-no-root.apk` | 直接安装免 Root 本地 VPN 版 |
| `XGuard-v0.9.3-source.zip` | 源码、构建脚本和许可证 |
| `SHA256SUMS.txt` | 校验下载文件的 SHA-256 |

同一版本类型可以用原签名覆盖升级。Root 与免 Root APK 使用相同的包名、不同的签名，切换前请备份所需设置。

两版均通过浏览器回归、APK 签名和打包校验。本次跳过真机测试，实际耗电变化尚未测量。
