# XGuard v0.9.5

- 打开 App 时自动检查 GitHub 正式版。发现适用的新版本会在权限引导或其他弹窗关闭后提示，也可从「设置 → 检查更新」手动检查。
- Root 模块版下载模块 ZIP，在 Root 管理器中安装后重启。配套 APK 仅用于补装管理界面，不能代替模块更新。
- 免 Root 版下载 APK 后，打开下载的文件并按 Android 提示覆盖安装。两版使用同一包名，不能混装。
- 包含 v0.9.4 的 CPU 忙循环及 hosts 挂载回退修复、应用白名单、小米社区和小米商城的内置开屏跳过规则。Root 模块版的系统 hosts 仍是全局共享的，应用白名单不能隔离该层拦截。

从不带更新提醒的版本升级到 v0.9.5，需要先手动下载对应的安装包。`SHA256SUMS.txt` 提供发布文件的校验值。
