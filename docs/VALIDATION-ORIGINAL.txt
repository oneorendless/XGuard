XGuard 0.8.3 验证记录

提高全局玻璃通透度，保留三级悬浮投影、描边与边缘高光。
- 浅色主卡片基底不透明度 76%→46%，统计 68%→38%，普通 66%→34%，操作 60%→30%。
- 深色主卡片基底不透明度 88%→56%，统计 82%→48%，普通 78%→42%，操作 72%→36%。
- 适度减弱顶部渐变，主功能 / 普通 / 操作卡片模糊分别为 5 / 4 / 3px。
- 导航与浮动按钮基底不透明度 26%，模糊 6px。
- 选中标签基底不透明度为浅色 16% / 深色 20%，模糊 7px，保留独立实时毛玻璃与折射。
- 弹窗基底不透明度为浅色 42% / 深色 48%，已提取为独立主题变量。
- 以上是材质底色的不透明度；顶部高光与边缘有额外叠层，不代表最终像素透明度。

本版检查通过：
- 五页面、深浅主题、320–960px 布局，Root 授权流程、检查弹窗多种关闭方式。
- 选中导航单独开关模糊与折射的实际背景像素验证，五个标签透镜对齐。
- 减少动画 / 透明度、无滤镜降级；无空闲持续 JS 重绘和纹理重建。
- 模拟 Root 延迟 900ms，连续切页 30 次，p95 10.1ms，6 次合并读取；仅为桌面 Edge 数据。
- 浅色概览、深色概览与检查弹窗预览已进行视觉检查。
- App / 模块统一为 0.8.3 / 8003；包名、名称、签名、资源、内置包一致性与 APK 对齐通过。
- 与 0.8.2 源码逐项比较，业务代码、规则数据、采集器二进制保持一致；源码无缓存或私钥，桌面副本哈希一致。

业务未改，沿用此前 Shell / 迁移 / Go / go vet 结果，未重复运行这些业务测试。
尚未连接 Android 真机；截图使用模拟接口数据，设备上的 WebView / GPU 效果仍需确认。

APK 可覆盖更新现有 XGuard；模块用户同步刷入 XGuard-v0.8.3.zip 后重启。source.zip 是源码，不能刷入。
