# v0.8.6 本地验证记录

日期：2026-11-16（北京时间）。本文记录 v0.8.6 发布前的本地构建、界面回归与设备检查范围。

## 已验证

- `node tests/ui-v085.mjs`：同时覆盖 Root 与免 Root 界面。验证状态先于慢统计显示、比例环图、HOSTS 能力边界、分钟记录图及排行、清空记录不重置累计、零值空环、VPN 历史拦截记录不随之后的放行规则改写。
- 同一浏览器脚本验证日志部分失败及关闭、返回，扫描深度选择与取消，更新间隔选择与保存、取消、失败不改原值、自定义 72 小时保留，以及深浅色、320px 布局、CSP 和已有开屏分组功能。
- `tests/stats-device.sh` 在连接的 SukiSU 设备上通过：轻量统计的 hosts 规则与挂载状态、来源详情省略、后台锁定快照，以及快照缺失和非法值处理。
- 两版 Java / DEX 编译、原签名校验与 APK 页面资源一致性校验通过。
- Root 配套 APK 已覆盖安装到当前设备，模块更新保留原配置与 hosts 文件。安装前备份保存在本地 `dist/device-check/xguard086-before-update.tar`，包含更新前模块和持久数据。
- 已看到实机统计页及 HOSTS 挂载状态。设备使用中，未继续抢占前台逐项操作；日志、扫描深度和更新间隔的交互验证来自浏览器自动化。

## 性能观测

同一设备顺序测量：原完整统计约 `7.47 s`，轻量统计约 `2.50 s`，下降约 67%；原状态接口约 `0.40 s`。界面现在先显示状态，不再等待统计完成。这些数值属于当前设备的单轮观测，不是通用性能保证，Android 首帧耗时也不等于防护连接就绪时间。

## 本轮未重复的检查

采集器和 VPN 转发逻辑未改动，本轮没有重复 Go 测试、DNS 探针和迅雷冷启动广告检查。免 Root 版没有覆盖安装到当前 Root 正式应用，也没有进行新的真实 VPN 转发测试；两版仍不能同时安装。
