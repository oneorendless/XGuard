# XGuard 0.8.3 渲染与交互

## 材质与配色

`theme.css` 统一定义用户指定的蓝色、背景、卡片基色、文字与分隔线色值，以及由这些基色派生的透明度、边缘高光和投影。主题自动跟随系统；保留双主题抽象光环 SVG 背景，将图案整体不透明度降至浅色 0.52 / 深色 0.48，减弱纹理对内容的干扰。

信息卡片使用独立半透明表面、顶部渐变高光、细描边、柔软大范围投影，统一 22px 圆角。主功能、统计、操作卡片按三个层次区分，不通过整体透明度影响文字或按钮的可读性。

| 卡片 | 浅色基底不透明度 | 深色基底不透明度 | 模糊 | 主投影范围 |
| --- | --- | --- | --- | --- |
| 主防护 / 采集状态 | 0.46 | 0.56 | 5px | 下移 20px、模糊 52px |
| 统计 | 0.38 | 0.48 | 4px | 下移 13px、模糊 36px |
| 操作 / 域名入口 | 0.30 | 0.36 | 3px | 下移 7px、模糊 24px |
| 设置 / 列表 / 其他信息 | 0.34 | 0.42 | 4px | 下移 10px、模糊 30px |

0.8.3 降低全部卡片的材质底色与表面渐变强度，同时适度减少模糊，让背景纹理更清楚地透出。三级悬浮投影、边缘描边与顶部细高光保留，避免卡片失去层次。主卡片与统计卡片间距为 18px，分组标题与编辑区保留充足留白；嵌套编辑区使用外层的一张玻璃表面，避免重复投影和滤镜。导航底板与浮动按钮基底不透明度为 0.26，模糊 6px；弹窗基底不透明度为浅色 0.42 / 深色 0.48，通过独立主题变量控制。

底栏的选中标签使用独立玻璃透镜：基底不透明度为浅色 0.16 / 深色 0.20，实时模糊 7px，叠加柔和顶部高光、白色细边与轻微投影；蓝色仅保留在选中图标和文字。导航底板与移动透镜是同级表面，外层导航不创建背景滤镜根，避免嵌套 backdrop-filter 只能采样父层内部内容。透镜跟随五个标签移动，文字始终位于独立前景。

背景 SVG 是原创图形，不是 Prismal 示例照片；不新增在线图片、CDN 或运行时网络依赖。界面保留 22px 卡片圆角、14px 控件圆角、线性图标与小面积蓝色交互反馈。

## 光学玻璃

复用 PrismalAGSL 的圆角矩形 SDF、梯度与 `1 - sqrt(1-x*x)` arc-lift 透镜曲线，在控件尺寸变化时生成位移纹理。浏览器 `backdrop-filter` 和 SVG `feDisplacementMap` 对**实时页面背景**执行低强度模糊及边缘折射；红色通道与其他通道在最强边缘处只相差约 0.12px，避免彩虹填色。文字属于独立前景层，不随背景折射。

本版不是直接集成 Compose / AGSL 运行时，也不再用整屏 WebGL 画布绘制背景。复用原开源算法、保留 MIT 许可和版权，使用现有 WebView 的合成与滤镜管线，在 App 和管理器 WebUI 之间共享实现。

## 性能和降级

- 光学位移仅用于底栏底板、选中标签透镜、浮动刷新按钮和已打开弹窗；普通卡片使用 CSS 毛玻璃，一个列表使用一个玻璃表面，不为每条域名创建滤镜。
- 位移图按尺寸缓存，最大纹理尺寸约 600×360；没有空闲时持续重绘的 JS / Shader 循环，滚动背景由浏览器合成器处理。
- 页面导航不等待 Root 命令；各页合并在途请求，规则 / 开屏页缓存 15 秒。域名页保持独立的 5 秒轮询，页面隐藏或退出后不继续触发轮询。晚到的请求不切换页面；域名请求有修订号检查。
- 页面进场 170ms，导航指示器 280ms 弹性过渡。按钮轻微缩放，原生触觉反馈遵循系统设置；减少动画偏好会关闭过渡和动画。
- 当前 Chromium 支持光学滤镜时启用折射；其他支持 backdrop-filter 的内核降级为实时毛玻璃；不支持模糊或用户要求降低透明度时使用纯色表面，保留功能与对比度。
- Android 声明硬件加速，具体滤镜是否走 GPU 仍取决于设备、WebView 和管理器实现，不能以桌面测试承诺真机帧率或续航。

## 功能与检查

首次打开先说明 Root 用途，只有用户确认后才调用 `su -c id -u`。UID 为 0 才记录已授权并读取模块；拒绝可重试，“稍后”不执行 Root 命令。防护检查使用独立弹窗，支持在检查进行中关闭，结果不会重新弹出或写回概览。

Playwright 验证主题、320–960px、五页面、实际背景折射像素变化、静止时不重建纹理、减少动画与透明度、无滤镜降级、Root 首次 / 拒绝 / 重试 / 记忆 / 稍后，以及检查结果的多种关闭方式。使用条纹背景，单独开关选中透镜的模糊与折射，比较像素，验证它确实处理背后内容；逐一检查五个标签的透镜对齐与导航预览。用 900ms 的模拟 Root 响应连续切换 30 次，具体浏览器耗时写入交付目录 `navigation-performance.json`。预览使用测试接口数据。

0.8.0 已完成 Shell 规则与迁移测试，以及 Go DNS/TLS 解析与异常输入测试；0.8.3 调整全局玻璃材质、版本与相关文档，业务逻辑与规则数据沿用这些结果。本版重新检查界面、APK / ZIP 包名、名称、版本、签名、所有 App assets 与模块 WebUI 内容一致、ZIP 中实际携带的 APK 校验值。未连接 Android 真机。
